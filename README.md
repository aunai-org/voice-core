# voice-core

Pure-Rust, offline library that measures how someone speaks from raw audio: pitch, loudness, pace, pauses and voice steadiness (jitter, shimmer, HNR).

Status: pre-alpha. See [docs/spec.md](docs/spec.md), [docs/plan.md](docs/plan.md) and [docs/roadmap.md](docs/roadmap.md).

License: MIT. No GPL code or dependencies; Praat/Parselmouth are used only as an offline test oracle.
